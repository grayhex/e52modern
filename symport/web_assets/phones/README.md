# Nokia E52 Silver handset artwork

Original generated high-resolution RGBA illustration for SymPort, created 2026-11-03.
This is a visual rendering of the E52 Silver, not a manufacturer-supplied photograph,
not a ROM and not evidence of E52 emulation compatibility.

Photographic shape/layout reference viewed: [GSMArena Nokia E52](https://www.gsmarena.com/nokia_e52-2792.php)
and its [product thumbnail](https://fdn2.gsmarena.com/vv/bigpic/nokia-e52.jpg).
The reference photograph is not shipped. Material/detail quality follows the existing
[MGO handset artwork](https://github.com/grayhex/MGO/tree/872f449719a40c80d5dfab4400f0736325828230/apps/web/public/phones),
without copying its renderer or emulator implementation.

`nokia-e52-silver.png` is the original 831×1893 generated output. The blank LCD has
no game/menu baked in: SymPort places real EKA2L1 frames over its measured rectangle.
`nokia-e52-silver.json` records measured display/control geometry, mirrored by scoped
CSS in `lab.css`. Keys are independent accessible HTML hit regions with pointer
capture. Mail has no binding because this MGO/EKA2L1 API has no dedicated email key.
Clear/Backspace is an explicitly external control, not an invented hardware key.

Artwork identity is independent of the actual installed firmware/model and frame
resolution, both displayed by Lab. Historical details have not been manufacturer
certified; key legends and metal shading are an illustration.
