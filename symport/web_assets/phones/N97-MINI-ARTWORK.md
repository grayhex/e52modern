# Nokia N97 mini handset artwork

`nokia-n97-mini.png` is a separate high-resolution RGBA, reference-based product illustration,
prepared for SymPort on 2026-11-05. It depicts the **bronze/dark-brown N97 mini with its slider
closed**, using the [original frontal product photograph](https://fdn2.gsmarena.com/vv/pics/nokia/nokia-n97-mini-2.jpg)
as the shape/control/material reference. The source photograph is not redistributed.

The compact rounded body, bronze rim, upper earpiece/camera/sensors, diagonal metal menu key,
green call and red end keys belong to Mini. No full-size N97 body, D-pad, exposed numeric keypad
or invented closed-slider QWERTY is reused. The background is transparent and the LCD is blank;
there is no menu, theme, personal information or simulated live output baked into it.

This is an image edit based on that reference, not a manufacturer-supplied photo or hardware
verification. Nokia marks identify the product. The original generated output is preserved;
the PNG is copied without stretching. Dashboard/Inspector use the same registry image with
`object-fit: contain`. S60 5th theme creation/preview remains unavailable: the decorative asset
does not add `artwork.screen` geometry, a theme pipeline or an emulator device.
