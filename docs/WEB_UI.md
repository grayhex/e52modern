# SymPort Workbench: браузерный интерфейс для E52Modern

Небольшая **локальная веб-панель** поверх существующего SymPort CLI. Она не заменяет
CLI и не требует Node.js, npm или внешнего веб-сервиса.

Возможности:
- Обзор инструментов через `doctor`, результаты проверок и сообщения об ошибках.
- Варианты E52 CLEAR Light/Dark: предпросмотр (схематичный), сборка, инспекция, упаковка.
- Выбор MakeSIS (при наличии) или **явно экспериментального** native writer.
- Скачивание обоев 240×320 PNG отдельно от темы, чтобы проверить их на телефоне независимо от SIS.
- Перечень и скачивание созданных SIS/SISX в браузере.
- Создание приложений в `workspace/<name>`, сборка, анализ, упаковка через установленный SDK.
- Поиск доступных устройств и передача SIS через API SymPort (если USB доступен **на сервере**).
- Выбор SIS для внешнего эмулятора; сам EKA2L1 и ROM в Docker не поставляются.
- Полные файловые копии карты (страница «Резервные копии»): создание с прогрессом, проверка SHA-256, восстановление по плану без
  перезаписи, удаление. Копии лежат на сервере; подробности и ограничения — в [PHONE_BACKUP.md](PHONE_BACKUP.md).
- Календарь и задачи через Gammu (только чтение, поиск, экспорт `.ics`/JSON) и поиск SIS/SISX на накопителе.
- Ручной чек-лист для Nokia E52, версия прошивки и заметки.
- Вывод команд и JSON-отчёты. Отчёты сохраняются в `build/symport/web-reports/`.

## Компактный макет

Стили `compact.css` загружаются после `app.css`: меньшие отступы, подключение и плитки в одну строку, карточки в несколько
колонок, длинные списки (копии, события, SIS) прокручиваются внутри карточки, второстепенное (ZIP одной папки, журнал, возможности
устройства) свёрнуто в `<details>`. При 1440×900 страницы «Телефон и файлы», «Резервные копии», «Календарь», «Приложения»,
«Темы», «Контакты» и «Музыка» занимают не более 1,3 высоты окна (проверяет `tools/check_web_ui.cjs`); на телефонной ширине
(390 px) горизонтальной прокрутки нет. Стили без `style=` в разметке — политика CSP `style-src 'self'` не ослаблялась.

## Docker на Linux-сервере (рекомендуется)

```sh
git clone https://github.com/grayhex/e52modern.git
cd e52modern
docker compose up -d --build
docker compose ps
```

Compose по умолчанию публикует порт **только** на `127.0.0.1:8765` сервера.
Он не должен быть открыт напрямую в Интернет.

На компьютере с Windows открой SSH-туннель (обычный Windows Terminal / PowerShell):

```powershell
ssh -L 8765:127.0.0.1:8765 user@your-linux-server
```

И открой в браузере **http://127.0.0.1:8765**. Не закрывай SSH-сессию,
пока пользуешься интерфейсом. Если на локальном ПК порт 8765 занят,
используй `ssh -L 8766:127.0.0.1:8765 ...` и URL `http://127.0.0.1:8766`.

Сборки и проекты остаются в Docker volumes `e52modern_symport-build` и
`e52modern_symport-workspace` при пересоздании контейнера.
**Не выполняй** `docker compose down -v`, если хочешь их сохранить.

Контейнер собирает Nokia `skc` и `bmconv` под Linux и запускается
от непривилегированного пользователя. По умолчанию не содержит
Windows MakeSIS, Wine, EKA2L1, firmware или полного native SDK.
Панель честно покажет недоступные операции.

Команда `symport theme package --backend native` создаёт экспериментальный,
неподписанный SIS, который не содержит все зависимости официального .pkg.
**Он не испытан на настоящей E52.** Для проверки приоритетнее официальный
MakeSIS/SignSIS с подходящей подписью, подключённый как внешний backend.
Не подменяй эти требования экспериментальным форматом.

Для локального запуска без Docker:

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -e '.[theme]'
tools/s60/build.sh
python -m symport.web --open
```

В обоих вариантах UI выполняет только заранее разрешённые команды SymPort,
а не произвольные shell-команды или пути.

## Когда физическая Nokia E52 приедет

1. Сохрани резервную копию и запиши RM/версию прошивки через `*#0000#`.
2. В разделе «Темы» собери, проверь, упакуй Light/Dark. Скачай файлы через UI.
3. Если устройство подключено к твоему Windows ПК, **удалённый Docker-сервер не
   увидит этот USB без отдельного проброса**. Передай SIS на телефон вручную
   по USB/карте памяти, либо запусти SymPort локально. Не нужен USB passthrough
   к публичному серверу.
4. Установи SIS вручную через файловый менеджер телефона.
5. В разделе «Телефон и тесты» заполни результаты проверки Active Standby,
   меню, полей ввода, приложений и перезагрузки; сохрани отчёт.
6. При ошибке установки запиши точный текст ошибки и версию прошивки;
   статус `device: pass` нельзя выставлять автоматически на основании компиляции.

Панель **не** удалённо устанавливает SIS, не управляет клавишами E52,
не снимает скриншоты с USB и не перепрошивает телефон.

## Безопасность

- Используй только SSH-туннель или равноценную защищённую приватную сеть.
- Не меняй публикацию порта на `0.0.0.0:8765:8765` без полноценной внешней
  аутентификации, TLS и правил доступа.
- Сервер допускает только `localhost`/`127.0.0.1` как Host, проверяет Origin
  и случайный токен сессии на записи.
- На сервере нет интерфейса для запуска произвольных команд, загрузки
  произвольных файлов или чтения произвольных путей.
- `workspace/` содержит только созданные через CLI проекты. При установке
  сторонних SDK проверяй происхождение и лицензии отдельно.
