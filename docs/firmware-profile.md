# Firmware-профиль (пользовательский)

Файл JSON или TOML, который вы создаёте сами из дампа прошивки своего E52. Не коммитьте чужие ROM.

```json
{
  "schema": 1,
  "id": "my-e52-fw",
  "device": "nokia-e52",
  "firmware_version": "(как показывает *#0000#)",
  "source": "как получен: дамп, инструмент, дата",
  "dlls": {
    "euser.dll":  {"ordinals": [1, 2, 3]},
    "avkon.dll":  {}
  }
}
```

`ordinals` — список экспортируемых ординалов; пустой/отсутствующий означает «DLL есть, таблица неизвестна»
(проверка ординалов пропускается с предупреждением). Использование: `--firmware-profile my-e52-fw.json`.
Автоматического импорта из образа ROM в SymPort нет (не реализовано).
