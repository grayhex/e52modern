# X-plore for Symbian

Исследование на 2026-11-04. Файловый менеджер Lonely Cat Games для Symbian (S60 3rd / 5th).

**Источники**

* Исходники: <https://github.com/mice777/X-plore-Symbian> — Apache-2.0, автор объявил код общественным достоянием в декабре 2015.
* Официальная бесплатная сборка автора: страница <https://www.lonelycatgames.com/apps/xplore-symbian>, файл
  `x-plore_s60_3rd_1_64.sisx` (версия 1.64, январь 2020), 510 612 байт, SHA-256
  `283c9a0b952e9f959e44b0138c61397decb165fa0354bab74c54a18a73ae2d5c`.

**Решение.** В каталог добавлена официальная сборка автора с закреплённым SHA-256 (`delivery: automatic`, загрузка только
с `www.lonelycatgames.com`, пакет не распространяется самим репозиторием). Проверка `symport sis inspect`: контрольные суммы
SIS и SHA-1 файлов верны; зависимости — платформа S60 3rd (`0x101F7961`, как в профиле E52) и S60 5th; capabilities
NetworkServices, LocalServices, ReadUserData, WriteUserData.

**Известные ограничения.** Сертификат пакета самоподписан («Lonely Cat Games») и **истёк 2025-10-23** — телефон может отклонить
установку; SymPort это не обходит. На физическом E52 пакет не проверялся.

**Воспроизводимая сборка не реализована.** README проекта требует Visual Studio 2008 и SDK Symbian 9.1 (S60 3rd), проект
собирается через `X-plore.sln`, а финальная упаковка выполняется Windows-утилитами автора (`Tools/Symbian/9.1/Link.bat`,
`E32ToLcg32`, `MakeCRC.exe`, `ZipMaker.exe`) со своим «заглушечным» `StubE32.exe`. Ни одного из этих компонентов нет в Linux-среде,
исходники под другим UID/сертификатом дали бы другой пакет, а проверить результат без телефона нельзя. Поэтому вместо
недоказуемой сборки используется официальный дистрибутив.
