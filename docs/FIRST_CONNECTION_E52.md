# Первое подключение Nokia E52 / E72

Начните с чтения и экспорта. Возможности определяет конкретное подключение, а не
наличие USB-кабеля. Прошивка телефона в SymPort отключена.

## Подготовка

- Зарядите телефон, разблокируйте экран. Сохраните существующую резервную копию
  Nokia Suite, если она есть; не удаляйте её после установки SymPort.
- Используйте исправный кабель передачи данных. На телефоне выберите **PC Suite**.
  На Windows установите доверенный Nokia Connectivity Cable Driver отдельно.
  Если COM-порт занят, закройте Nokia Suite и другие программы работы с телефоном.
- [Запустите SymPort в Docker](DOCKER_DEPLOYMENT.md). При удалённом сервере Bridge
  на ПК должен открывать его HTTPS-адрес. Доступ к серверу защитите аутентификацией.
- [Скачайте portable Windows Bridge](WINDOWS_BRIDGE.md), проверьте `SHA256SUMS.txt`,
  распакуйте весь архив и запустите `SymPortBridge.exe`. Подпись Authenticode пока
  отсутствует; не отключайте защиту Windows глобально.
- В SymPort: **Настройки → Подключение → Запросить доступ**. Подтвердите точный
  адрес SymPort в Windows и доступ браузера к локальной сети, если он запросит его.

## Проверка чтения

1. **Найти телефон**, выбрать соединение. Записать модель, RM, версию прошивки,
   название транспорта. Убедиться, что выбрана E52/E72, а не отдельный том карты.
2. **Инструменты → Диагностика → Прочитать показатели**, экспортировать JSON.
   Батарея, сигнал, USB-режим или счётчик часов могут отсутствовать. Это допустимо;
   значок «Нет данных» не означает ноль или неисправность аккумулятора.
3. **Файлы:** открыть доступные диски, скачать небольшой существующий файл.
   Mass Storage даёт только явно доступные файлы карты, не внутренний `C:/` и не PIM.
4. **Контакты, Сообщения, Календарь:** сначала прочитать и экспортировать доступные
   хранилища. При неподдерживаемом драйвере используйте экспорт Nokia Suite
   (vCard/iCalendar); Google Contacts — Google CSV/vCard, Apple Contacts — vCard.
5. **Резервные копии:** сохранить доступную папку файлов и отдельные копии PIM,
   если транспорт их читает. Файловая копия не содержит прошивку или весь телефон.

## Первая запись — после копий

1. В файловом менеджере создать новую папку, загрузить небольшой неперсональный
   файл с уникальным именем, скачать обратно и сравнить содержимое. Существующие
   файлы не перезаписываются. Удаление проверять только на этом тестовом файле.
2. Проверить законно полученный SIS через **Certificate Inspector** и, если
   загружена подходящая пользовательская прошивка, **Emulator Lab**. Записать
   точный текст ошибки сертификата/зависимости. Проверка эмулятора не заменяет телефон.
3. Передать один пакет, завершить установку на экране Nokia. Не передавать большой
   набор до успешной проверки одиночного файла. Тему применять в меню «Темы».
4. Для контактов/календаря сначала проверить dry-run/план изменений на одной записи;
   запись доступна только с повторным чтением. Отправку SMS не проверять без
   отдельно подтверждённого профиля и явного согласия: это может стоить денег.
5. Отключить/подключить кабель, снова найти телефон и повторить чтение. После сбоя
   записи сначала прочитать текущее состояние, затем решать, нужна ли повторная операция.

## Если телефон не найден

Проверьте кабель, PC Suite, драйвер/COM-порт, отсутствие блокировки Nokia Suite,
статус Bridge в трее и разрешённый адрес. Запустите диагностику подключения в UI.
Не подменяйте драйвер USB через Zadig и не включайте системные патчи ради обнаружения.
Для Bluetooth сначала выполните сопряжение в Windows, затем используйте доступный
RFCOMM/OBEX-профиль. OBEX может поддерживать только передачу файлов; Gammu-функции
зависят от собранного драйвера. Отсутствующий ObexFTP показывается как отсутствующая
зависимость. Подробности: [TRANSPORTS.md](TRANSPORTS.md).

Сохраните диагностический отчёт, транспорт, версии Windows/Bridge и точные сообщения
об ошибках. Не публикуйте IMEI, контакты, SMS и приватные архивы. Факт установки/запуска
фиксируется только по наблюдению на вашем телефоне.
