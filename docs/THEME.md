# Сборка темы E52 CLEAR

```bash
tools/s60/build.sh                       # один раз
symport theme build                      # обе темы (или --variant light|dark)
symport theme inspect                    # статическая проверка; добавьте --reproducible для двойной сборки
symport theme inspect --json --report build/reports/theme.json
```

Прямые команды остаются рабочими и неизменными:

```bash
tools/s60/build.sh
python3 tools/build_theme.py [light] [dark]
python3 tools/s60/s60inspect.py theme/dist/light/e52clearlight
```

`symport theme build` вызывает `tools/build_theme.py` как внешний процесс, затем запускает те же проверки,
что и `theme inspect`.

## Что проверяет `theme inspect` (всё — статическая корректность)

| Группа | Проверки |
|---|---|
| Структура | `.skn` — длина = размеру файла, имена `.mbm/.mif` в теле; `.mbm` — UID, trailer, заголовки растров; `.mif` — заголовок, таблица смещений, каждый индекс указывает на растр, все растры задействованы (низкоуровневая логика — `tools/s60/s60inspect.py`) |
| Соответствие файлов | порядок, размеры и глубина растров в `.mbm` совпадают с `theme/src/<variant>/skin.txt` и `gfx/*.bmp` (включая маски); число иконок `.mif` = числу записей |
| PKG | разбор; платформенная зависимость S60 3.x (`0x101F7961`) обязательна; зависимости `0xA00000EB`, `0x10207113`; пути установки `\resource\skins\<uid>` и `\private\10207114\import\<uid>`; вендор |
| UID | `.pkg` = PID1 в `.skn` = `skin.txt` = имя каталога; различны у Light/Dark; класс диапазона и риск коллизий |
| Палитра | пересчёт WCAG-контраста, порог 4.5:1, согласованность с `colours.json` |
| Манифест | `manifest.json`: структурный статус, `physical_device: not-tested`, экран 240×320 |
| Воспроизводимость | `--reproducible`: две сборки в изолированных копиях; единственное допустимое отличие — 8-байтовая метка времени в блоке Information `.skn` |

Вне статических проверок и поэтому всегда `unknown` в отчёте: принятие темы прошивкой E52
(`firmware.acceptance`) и установка на телефон (`device.install`).

## Геометрия

Тема не меняет и не заявляет изменения положения часов, структуры Active Standby, компоновки меню 3×4,
количества ярлыков, назначения клавиш и структуры системных диалогов. Эталон — `reference/00_original_user_240x320.png`.
Превью `theme/preview/*` — схематичные макеты на собственных ресурсах темы, а не скриншоты телефона.
Пиксельные ресурсы (PNG/BMP) зависят от версии Pillow; побайтово сравнивается только повторная сборка в одной среде.
