# Дизайн SymPort: Nokia Classic

Интерфейс React приведён к **Nokia Classic** — деловой облик Nokia PC Suite / Eseries эпохи S60 3rd FP2
(2008–2010) в современной адаптации. Спецификация — [design/nokia-classic.md](design/nokia-classic.md);
Nimbus (cyan `#22D3EE`, blue `#0E74E9`, радиус 16 px) больше не основа интерфейса. Откат на прежний
вид — `/classic` (старый HTML, не тронут).

Фирменный цвет **`#124191`** подтверждён источником; остальные значения — проектные токены
«в духе эпохи», а не восстановленный брендбук Nokia. Логотип — собственный вектор классического
сплошного wordmark (`web_assets/brand`), официальная связь с Nokia не заявляется. Шрифты Nokia не
используются (стек `Segoe UI, Tahoma, Arial`).

| Параметр | Реализация |
|---|---|
| Токены | `symport/web_assets/nokia-classic.css`: `--nokia-*` (light/dark), старые `--bg/--panel/--blue…` указывают на них |
| Каскад | `frontend/src/styles.css`: `@layer legacy, theme, base, utilities`; прежние CSS и Nokia Classic — в `legacy`, утилиты Tailwind только для файлового браузера — выше |
| Акцент | `#124191` (light); в dark — `#91B8FF` для контраста, логотип — белый вариант |
| Поверхности | canvas `#F1F3F6`, панели белые, граница `#CBD3DC`, радиус 5–7 px, без тяжёлых теней |
| Статусы | цвет + иконка + текст (`status-chip`), зелёный только для успеха/подключения |
| Навигация | боковая панель 232 px, активный пункт — `brand-soft` и полоса 3 px слева; см. [NAVIGATION.md](NAVIGATION.md) |
| Дашборд | MUI (Card, Chip, LinearProgress, Stack) + `@mui/x-charts`, тема `dashboard/muiTheme.ts` на токенах Nokia; только значения, которые отдаёт транспорт |
| Файловый браузер | `@harryy/react-file-browser`, токены `--fb-*` привязаны к `--nokia-*` |
| Иконки | Lucide, 18 px, `currentColor`, подписи сохранены |
| Доступность | skip-link, фокус-кольцо, `aria-current`, `aria-expanded`, `inert` для скрытого меню, reduced-motion, касания ≥ 44 px на телефоне |

Не реализовано из спецификации (честно): набор before/after-снимков для всех разделов и light/dark на 390 px
для каждой страницы; Ringtone Studio, Emulator Lab и Jailbreak получили токены и общие компоненты, но не
перерисованы отдельно. Скриншоты в [screenshots/](screenshots/) сняты с работающего UI.

## История: Nimbus

Ниже — прежнее описание Nimbus; оно сохранено для `/classic` и контекста.

| Параметр | Реализация |
|---|---|
| Белый фон / тёмная поверхность `#082F49` | Белые рабочие карточки, тёмный приветственный блок и Emulator Lab |
| Cyan `#22D3EE`, blue `#0E74E9` | Активная навигация, фокус, статусы и основные действия |
| Текст `#111827`, вторичный `#4B5563`, граница `#E5E7EB` | Общие CSS tokens |
| Inter / JetBrains Mono | Локальные variable-шрифты и OFL-лицензии в `web_assets/fonts/` |
| Радиус 16 / 8 / pill | Карточки / элементы управления / статусы |
| Крупная типографика, bento | Заголовок Lab 48 px (64 на широком экране), экран телефона и соседние панели |
| Рабочая плотность | Боковая навигация, таблицы и внутренний скролл сохранены; размеры адаптированы к инструменту |
| Доступность | Подписанные поля, фокус клавиатуры, live status, reduced-motion, отключённые функции с причиной |

`nimbus.css` обновляет общую систему поверх прежнего компактного макета;
`lab.css` добавляет компоненты Lab и точные зоны ввода поверх серебристого корпуса E52.
Оригинальная иллюстрация, измерения и источники описаны в
[phones/README.md](../symport/web_assets/phones/README.md). В браузере нет внешних запросов за шрифтами.
Прежние шрифты остаются доступными для совместимости, но текущий интерфейс использует новые.

Проверки Chromium: 1440×1100 и 390×844, импорт/экспорт контактов, файлы/медиа,
пакеты, каталог, копии, календарь, библиотека и Emulator Lab. Нет горизонтального
переполнения документа и ошибок JavaScript. Тесты транспорта используют отдельные
временные тома и явно обозначенные fixtures.

Скриншоты [screenshots/](screenshots/) показывают реальные пустые состояния приложения
и настоящий агент MGO **без ROM**. Mock-скриншоты из `check_emulator_lab.cjs` остаются
в `build/screenshots/*contract*` и CI artifacts: они подписаны `TEST DOUBLE` и не
выдаются за аппаратную проверку. Успешная загрузка E52 и внешний вид применённой темы
потребуют пользовательской прошивки.

## Графика из nokia-symport-assets.zip

Подключены исходные логотипы, favicon/app icon, 18 навигационных SVG и matching
плитки карточек. Исходники лежат в `web_assets/brand`, `web_assets/icons`;
`graphics.json` сохраняет SHA-256 оригинальных файлов. Навигация использует SVG
непосредственно в HTML; активные состояния и голубая палитра задаются CSS Nimbus.
Подписи ссылок и кнопок сохранены, декоративные SVG скрыты от screen reader.
Изображения самодостаточны, внешних ресурсов/скриптов в них нет.

Файлы из preview архива не используются как интерфейс. Логотип предоставлен для
независимого проекта; официальная связь с Nokia не заявляется. В архиве нет
нового корпуса телефона, поэтому серебристая E52 из предыдущего шага сохранена.

## UI-kit и единая система (React)

React-интерфейс собран из одного набора блоков `frontend/src/components/kit` со стилями
`frontend/src/kit.css` (слой `theme`, поверх legacy-CSS): `PageHeader`, `SectionPanel`,
`StatusIndicator`, `EmptyState`, `ErrorState`, `Metric`, `ActionToolbar`, `DeviceIdentity`,
`Skeleton`, `GenericPhone`. Правила:

- сетка отступов 4/8 px (`--k-1…--k-6`), радиусы 5 px (контрол) и 7 px (панель), высота контрола 36 px;
  цвета — только токены `--nokia-*`; никакого inline-стиля (CSP `style-src 'self'`), доли
  прогресса — классами `k-bar-N`;
- статус — текст + значок + рамка, не цвет: `ok`, `warn`, `bad`, `unknown` («не проверено», пунктир),
  `off` («не поддерживается»), `info`; «не проверено» никогда не оформляется как «не работает»;
- MUI используется **только для графиков** (`ChartTheme`); карточки, кнопки и поля — kit/legacy
  Nokia Classic, поэтому дашборд визуально не отличается от остальных экранов;
- заголовок каждой страницы — `PageHeader`, названия совпадают с пунктами меню (RU/EN);
- `@harryy/react-file-browser` не имеет локализации: `components/fileBrowserLocale.ts` переводит
  его подписи по точному словарю (имена файлов не затрагиваются); токены `--fb-*` привязаны к `--nokia-*`;
- каталог приложений: компактная карточка (значок, название, версия/формат/категория), происхождение
  («Проверенный установщик (SHA-256)» или «Внешняя ссылка») и совместимость показываются отдельно.

**Главная страница:** герой с крупным изображением модели (из реестра, см.
[DEVICE_MODELS.md](DEVICE_MODELS.md)), имя/прошивка/RM, источник идентификации, только реально доступные
действия (остальные названы одной строкой); затем только измеренные показатели (отсутствующие
перечислены «не сообщается»), графики на реальных данных (кольцо накопителя для явно связанного тома,
операции за 7 дней, батарея/сигнал — только при ≥3 реальных измерениях), состояние и журнал. До подключения —
полноценное пустое состояние с шагами и ссылкой на мастер.

Проверки: `tools/check_layout.cjs` (15 экранов × 390/768/1366/1920 px × RU/EN: нет горизонтального
переполнения, у всех контролов есть имя, виден фокус, первый экран 1366×768 показывает телефон,
статус и действия), vitest, `tools/capture_screenshots.cjs`.

## Тема и локализация

> **Тёмная тема отключена** (`DARK_THEME_ENABLED = false` в `frontend/src/state/app.tsx`, `uiDarkEnabled` в `preferences.js`): интерфейс всегда светлый, в оригинальных цветах Nokia (`#124191`). Токены тёмной темы сохранены в CSS для возможного включения; сохранённый выбор пользователя игнорируется, пока флаг выключен.


Тёмные поверхности `#041C2E` / `#082F49`, контрастный текст `#EDF6FB`, cyan `#22D3EE`
и мягкие границы сохраняют структуру Nimbus. Приложение поддерживает RU/EN и
системную, светлую и тёмную темы. Каталог переводов локален; raw JSON, исходные
пользовательские значения и имена файлов сохраняются. Проверены переключение,
восстановление настроек после reload, отсутствие непереведённых русских UI-строк
на английских страницах и мобильное переполнение.
