# Проверка дизайна SymPort

Визуальный референс — приложенный Verdana Health Design System. Скриншоты Nokia
PC Suite / Nokia Suite использованы как примеры задач и группировки функций,
а не как требование воспроизвести старые Windows-панели.

| Параметр референса | Реализация |
|---|---|
| Background `#F8FAFC`, Surface `#FFFFFF` | Фон рабочего пространства и белые карточки |
| Navy `#0F172A`, Slate `#64748B`, Sage `#059669` | Основной текст/кнопки, вторичный текст, активная навигация и ссылки |
| Plus Jakarta Sans, DM Sans, Fira Code | Локальные шрифты, без внешних запросов браузера; OFL-лицензии рядом с файлами |
| Сетка 8 px, радиус 8 px | Основные карточки, поля и кнопки; шаги, отступы 16/24/32/48 |
| Воздух и постепенное раскрытие | Карточки задач, отдельные страницы, ограничения в details, импорт в три шага |
| Чёткие состояния | Disabled без подключённого транспорта, сообщения об ошибках и частичной проверке |
| Доступность | Подписанные поля, SVG-иконки, keyboard focus, live status, уменьшение анимации |
| Адаптивность | Две сетки на desktop, один столбец на mobile, таблица с локальным горизонтальным скроллом |

Проверено в системном Chromium: desktop 1440×1100 и mobile 390×844, без ошибок
JavaScript и горизонтального переполнения документа на mobile. Автотест проходит
импорт Google CSV, поиск, экспорт vCard, подтверждённую передачу контактов и файлов
на временный тестовый том. Это проверка UI/backend, а не совместимости с телефоном.

Скриншоты в [screenshots/](screenshots/) показывают начальные реальные состояния
приложения. Телефон не подключён; демоустройства и демонстрационные контакты в
приложение не добавлены. Контакты тестов вымышлены и используются только в тестах.

Существенные ограничения: аппаратная поддержка Gammu зависит от драйвера/прошивки;
файловый транспорт не читает SMS и реестр приложений. Передача ПО не доказывает
установку. Загрузка медиа не проверяет возможность декодирования на Symbian.
