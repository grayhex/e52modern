# Дизайн SymPort: Nimbus

Текущий визуальный референс — приложенный `nimbus-the-wallet-built-for-everyone-DESIGN.md`.
Его параметры применены к существующим сценариям SymPort: телефон, данные,
каталог, темы и разработка. Предметная область кошелька в приложение не переносится.

| Параметр | Реализация |
|---|---|
| Белый фон / тёмная поверхность `#082F49` | Белые рабочие карточки, тёмный приветственный блок и Emulator Lab |
| Cyan `#22D3EE`, blue `#0E74E9` | Активная навигация, фокус, статусы и основные действия |
| Текст `#111827`, вторичный `#4B5563`, граница `#E5E7EB` | Общие CSS tokens |
| Inter / JetBrains Mono | Локальные variable-шрифты и OFL-лицензии в `web_assets/fonts/` |
| Радиус 16 / 8 / pill | Карточки / элементы управления / статусы |
| Крупная типографика, bento | Заголовок Lab 48 px (64 на широком экране), экран телефона и соседние панели |
| Рабочая плотность | Боковая навигация, таблицы и внутренний скролл сохранены; размеры адаптированы к инструменту |
| Доступность | Подписанные поля, фокус клавиатуры, live status, reduced-motion, отключённые функции с причиной |

`nimbus.css` обновляет общую систему поверх прежнего компактного макета;
`lab.css` добавляет компоненты Lab и точные зоны ввода поверх серебристого корпуса E52.
Оригинальная иллюстрация, измерения и источники описаны в
[phones/README.md](../symport/web_assets/phones/README.md). В браузере нет внешних запросов за шрифтами.
Прежние шрифты остаются доступными для совместимости, но текущий интерфейс использует новые.

Проверки Chromium: 1440×1100 и 390×844, импорт/экспорт контактов, файлы/медиа,
пакеты, каталог, копии, календарь, библиотека и Emulator Lab. Нет горизонтального
переполнения документа и ошибок JavaScript. Тесты транспорта используют отдельные
временные тома и явно обозначенные fixtures.

Скриншоты [screenshots/](screenshots/) показывают реальные пустые состояния приложения
и настоящий агент MGO **без ROM**. Mock-скриншоты из `check_emulator_lab.cjs` остаются
в `build/screenshots/*contract*` и CI artifacts: они подписаны `TEST DOUBLE` и не
выдаются за аппаратную проверку. Успешная загрузка E52 и внешний вид применённой темы
потребуют пользовательской прошивки.

## Графика из nokia-symport-assets.zip

Подключены исходные логотипы, favicon/app icon, 18 навигационных SVG и matching
плитки карточек. Исходники лежат в `web_assets/brand`, `web_assets/icons`;
`graphics.json` сохраняет SHA-256 оригинальных файлов. Навигация использует SVG
непосредственно в HTML; активные состояния и голубая палитра задаются CSS Nimbus.
Подписи ссылок и кнопок сохранены, декоративные SVG скрыты от screen reader.
Изображения самодостаточны, внешних ресурсов/скриптов в них нет.

Файлы из preview архива не используются как интерфейс. Логотип предоставлен для
независимого проекта; официальная связь с Nokia не заявляется. В архиве нет
нового корпуса телефона, поэтому серебристая E52 из предыдущего шага сохранена.

## Nimbus Dark и локализация

Тёмные поверхности `#041C2E` / `#082F49`, контрастный текст `#EDF6FB`, cyan `#22D3EE`
и мягкие границы сохраняют структуру Nimbus. Приложение поддерживает RU/EN и
системную, светлую и тёмную темы. Каталог переводов локален; raw JSON, исходные
пользовательские значения и имена файлов сохраняются. Проверены переключение,
восстановление настроек после reload, отсутствие непереведённых русских UI-строк
на английских страницах и мобильное переполнение.
