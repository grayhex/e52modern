# Ограничения

- Возможности определяет выбранный транспорт. Mass Storage — файлы; AT, S60 Remote,
  FTP и OPP не взаимозаменяемы. [Матрица](TRANSPORTS.md).
- Передача SIS/JAR не подтверждает установку. Эмулятор не подтверждает работу на телефоне.
- Сложные повторения/поля календаря и неподдерживаемые хранилища остаются недоступны.
  Личные данные изменяются только с предпросмотром, копией и повторным чтением.
- Полные файловые backup jobs требуют томов сервера. Через Bridge — выбранная папка/PIM.
- Прошивка физического телефона отключена. Для Emulator Lab пользователь предоставляет
  собственную прошивку; проприетарных ROM в образе нет.
- E52 CLEAR содержит портретные ресурсы. Профиль E72 320×240 не конвертирует их автоматически.
- Ringtone Studio работает в Linux backend с FFmpeg. Ограничения размера, времени и
  временного хранения описаны в [RINGTONE_STUDIO.md](RINGTONE_STUDIO.md).
- Revive не устанавливает программы и не пишет в системные разделы: файлы копируются, установку завершает
  пользователь. Системные патчи — закрытая категория, откат системной DLL после удаления SIS невозможен.
- Reborn Hybrid CFW — alpha одного автора, без процедуры удаления; N95 8GB блокируется до подтверждения.
- Контейнеры FPSX, VPL и образы ROFS не декодируются; поиск уязвимых шаблонов — подсказка, отсутствие
  совпадений не доказывает безопасность.
- Device Agent для телефона пока не собран: заметки, настройки приложений и системные базы недоступны.
- Официальные MakeSIS/SignSIS — внешние инструменты. Нативный SIS writer не заменяет
  их политику установки/подписи. Inspector проверяет математическую подпись, но не
  может гарантировать доверие сертификату на конкретной Nokia.

Как проверяется проект и что подтверждено на устройстве — в [STATUS.md](STATUS.md).
