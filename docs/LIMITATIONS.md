# Текущие ограничения

* **Физический Nokia E52 недоступен**: тема и приложения на реальном телефоне не проверялись. Статус везде
  `physical_device: not-tested`.
* `.sis` для темы: официальный `makesis` в этой среде отсутствует; собственный писатель — экспериментальный,
  без подписи и без зависимостей, не принят MakeSIS/телефоном.
* Подпись: SymPort не проверяет её криптографически; политика установки на E52 не выяснена.
* `.mif` для тем: растровый `mifbuild.py` (формат выведен из кода ридера Nokia), SVG не поддерживается.
* Тема переопределяет фон, рамки (список, меню, popup, ввод) и цвета; остальное — системные ресурсы телефона.
* `symbian-platform` и его нативный SDK в среде разработки не устанавливались и не запускались: `app init/build/package`
  и `device *` проверены только на поддельном `symbian`. SIS-писатель SDK не упаковывает темы/DLL/зависимости.
* EKA2L1: нет документированного CLI, команда запуска задаётся пользователем; реальный запуск не проверялся.
* E32-анализатор: несжатые EKA2-образы с V-заголовком; сжатые — только заголовки. Парсер проверен на синтетических
  образах (`tests/helpers.py`), а не на образцах прошивок. Ресурсы `.rsc`, версия ОС и доступность API не анализируются
  без firmware-профиля, которого SymPort не поставляет.
* Профиль E52: поля `product_code`, `firmware.version`, `rom_dlls`, память, `signing_policy` — `unknown`.
* Не реализованы (P3): SDL-шаблоны игр, порт C/C++ библиотек, диагностический агент на Symbian, расширенная автоматизация
  тестов железа, профили других устройств (механизм есть — файлы в `profiles/`).
