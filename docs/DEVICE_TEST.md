# Установка и тестирование на Nokia E52

```bash
symport device list
symport device info [--device SELECTOR]
symport device stage build/symport/theme/light/e52clearlight.sis [--device SELECTOR]
```

Команды делегируются `symbian device ...` (symbian-platform). `stage` **только копирует** SIS в `Installs/`
телефона (смонтированный том или MTP) и проверяет SHA-256 — установку подтверждаете вручную на телефоне.
Не реализованы и не заявляются: удалённая установка/запуск, TRK-отладка, скриншоты и управление телефоном по USB,
перепрошивка, стирание данных, режимы восстановления.

Без `symbian-platform` команды завершаются кодом 3 с инструкцией. **В этой среде физический E52 недоступен;
ни одна из этих команд на реальном телефоне не выполнялась.**

## Ручной чек-лист

Заполните `docs/device-test-report.template.json` (скопируйте, не правя шаблон) и приложите к PR.
Пока он не заполнен, статус темы и приложений — `physical_device: not-tested`.

1. **Идентификация.** Модель (E52-1), код RM, версия прошивки (`*#0000#`), язык, свободная память,
   режим «Установка ПО» (Параметры → Диспетчер приложений → Параметры), наличие карты памяти.
2. **Резервная копия** данных и знание способа вернуть стандартную тему.
3. **Передача.** `device stage` или ручное копирование; хеш SHA-256 из отчёта.
4. **Установка.** Результат (успех/ошибка) и точный текст сообщения; предупреждения о сертификате.
5. **Тема.** Применение (Параметры → Оформление → Темы), перезагрузка телефона, стабильная загрузка.
6. **Интерфейс.** Фон, подсветка списка, меню 3×4, окно «Параметры», поле ввода, софт-клавиши, индикаторы;
   Заметки/Календарь/Калькулятор (светлый и тёмный вариант); входящий вызов; читаемость на свету;
   геометрия не изменилась по сравнению с `reference/00_original_user_240x320.png`.
7. **Приложение** (для P1): запуск из меню, текст, клавиши/софт-клавиши, корректное закрытие.
8. **Удаление.** Диспетчер приложений → удалить; возврат стандартной темы; остатки в `\resource\skins`.
9. **Итог:** что работает, что нет, ссылки на фото/скриншоты (снимать на камеру, не по USB).
