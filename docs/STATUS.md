# Словарь статусов и текущее состояние

Везде в SymPort и в документации различаются пять уровней доказательства. Более высокий уровень
**не следует** из более низкого.

| Уровень | Что означает | Откуда берётся |
|---|---|---|
| **Реализовано** | код есть и вызывается | исходники |
| **Проверено автотестами** | поведение подтверждено pytest/CI без устройства и без проприетарного SDK | `tests/`, `.github/workflows/ci.yml` |
| **Проверено в эмуляторе** | запуск в EKA2L1 с подтверждёнными результатами | отчёт `emulator test` (в этом репозитории **не выполнялось**) |
| **Проверено на устройстве** | ручной чек-лист на физическом Nokia E52 | `docs/DEVICE_TEST.md` (в этом репозитории **не выполнялось**) |
| **Не реализовано** | нет кода | см. «Ограничения» |

Статусы совместимости бинарников: `compatible`, `incompatible`, `unknown`, `not-tested`.
`compatible` выдаётся только при пользовательском firmware-профиле, разрешающем все импорты, и
означает *статическую* совместимость (`runtime: not-tested`).

## Матрица возможностей (на момент последней сборки)

| Возможность | Реализовано | Автотесты | Эмулятор | Физический E52 |
|---|---|---|---|---|
| `doctor`, `profile` | да | да | — | — |
| `theme build` (skc + bmconv + mifbuild) | да | да (CI пересобирает обе темы) | не проверялось | **не проверялось** |
| `theme inspect` (SKN/MBM/MIF, PKG, UID, палитра, манифест, воспроизводимость) | да | да | — | — |
| `theme package --backend makesis/signsis` | адаптер к официальным инструментам | с поддельными `makesis`/`signsis` | не проверялось | **не проверялось** (в этой среде официального `makesis` нет) |
| `theme package --backend native` | **экспериментально** (собственный писатель, без подписи и без зависимостей) | да (круговая проверка собственным читателем) | не проверялось | **не проверялось** |
| `sis inspect` | да (структурно, без проверки подписей) | да | — | — |
| `app analyze/inspect` для E32 | да (заголовки, импорты, capabilities) | да (синтетические образы) | — | — |
| `app init/build/package` | адаптер к `symbian-platform` | с поддельным `symbian` | не проверялось | не проверялось; **реальный SDK в этой среде не запускался** |
| `emulator list/test` | адаптер, команда задаётся пользователем | с поддельным эмулятором | реальный EKA2L1 не запускался | — |
| `device list/info/stage` | адаптер к `symbian device` | с поддельным `symbian` | — | **не проверялось** |
| Установка/запуск на E52, TRK, скриншоты по USB | **не реализовано** | — | — | — |

Тема E52 CLEAR: файлы `.skn/.mbm/.mif/.pkg` собраны компилятором Nokia; на физическом E52 **не проверялись**.
