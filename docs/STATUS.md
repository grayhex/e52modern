# Словарь статусов и текущее состояние

Везде в SymPort и в документации различаются пять уровней доказательства. Более высокий уровень
**не следует** из более низкого. Новый промежуточный уровень «сверено с реальным SDK» доказывает только согласие
с независимой реализацией формата — но не принятие образа прошивкой E52.

| Уровень | Что означает | Откуда берётся |
|---|---|---|
| **Реализовано** | код есть и вызывается | исходники |
| **Проверено автотестами** | поведение подтверждено pytest/CI без устройства и без проприетарного SDK | `tests/`, `.github/workflows/ci.yml` |
| **Сверено с реальным SDK** | результат совпал с независимой реализацией, запущенной в среде разработки (`symbian-platform` 0.3.0, Linux); это не прошивка и не телефон | `tests/fixtures/`, `tools/sdk/verify-real-sdk.sh` |
| **Проверено в эмуляторе** | запуск в EKA2L1 с подтверждёнными результатами | отчёт `emulator test` (в этом репозитории **не выполнялось**) |
| **Проверено на устройстве** | ручной чек-лист на физическом Nokia E52 | `docs/DEVICE_TEST.md` (в этом репозитории **не выполнялось**) |
| **Не реализовано** | нет кода | см. «Ограничения» |

Статусы совместимости бинарников: `compatible`, `incompatible`, `unknown`, `not-tested`.
`compatible` выдаётся только при пользовательском firmware-профиле, разрешающем все импорты, и
означает *статическую* совместимость (`runtime: not-tested`).

## Сверено с реальным SDK (symbian-platform 0.3.0, Linux x86_64, Clang 18, 2026-11-03)

| Что | Результат |
|---|---|
| `symbian doctor`, ARM-проба, сборка `probes/e32_probe` для ARMv5T | работают с системным Clang/LLD/CMake и Ninja ≥ 1.12 |
| `symport app build --mode toolchain` → `app package` → `app analyze --cross-check` → `sis inspect` | вся цепочка проходит на реальных файлах |
| Заголовок E32: мой разбор против `symbian inspect --format e32` | 15 полей совпали на реальном образе |
| SIS от писателя SDK: мой читатель против `symbian inspect --format sis` | совпали UID, имя, вендор, версия, файл, SHA-1; подписанный пакет распознан как подписанный |
| Мой `native`-писатель против писателя SDK | **байт-в-байт идентичный файл** при тех же входных данных; инспектор SDK принимает мой файл |
| Импорты E32 | **не проверены на реальных данных**: сборка образа с импортами не удалась (см. docs/LIMITATIONS.md) |
| Нативный SDK (`symbian sdk install`), `app init`, GUI-пример | **не установлены/не собирались** |

Это совпадение с *независимой реализацией формата*, а не принятие прошивкой E52 и не результат на телефоне.

Тема E52 CLEAR: файлы `.skn/.mbm/.mif/.pkg` собраны компилятором Nokia; на физическом E52 **не проверялись**.
