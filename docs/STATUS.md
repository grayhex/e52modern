# Возможности и проверка

Актуальное описание продукта — [README](../README.md), подключения —
[TRANSPORTS.md](TRANSPORTS.md), установка — [DOCKER_DEPLOYMENT.md](DOCKER_DEPLOYMENT.md).
Этот документ описывает значения статусов для разработчиков.

- `installed` — установщик сообщил результат установки; это не запуск.
- `launched` — подтверждён запуск в указанной среде.
- `failed` — операция завершилась ошибкой.
- `unsupported` — выбранная среда/транспорт не предоставляет функцию.
- `not-tested` — результата проверки нет.

Для каждого подключения матрица возможностей (`capability_matrix`) показывает эти статусы по
операциям, источник и время проверки; запись никогда не проверяется «пробной записью», а чтение
не означает запись — см. [TRANSPORTS.md](TRANSPORTS.md#capability-matrix-single-source-of-truth).

Структурная проверка SIS, математическая подпись, доверие сертификату на телефоне,
успех эмулятора и работа на реальном устройстве — разные результаты.
Статическая совместимость `compatible` не подтверждает runtime-совместимость.

## Как проверяется проект

Это единственное место, где описано, что именно подтверждено; интерфейс не повторяет этих оговорок на каждой странице.

* **Автоматически (CI):** Python 3.11–3.13, реальные FFmpeg-кодеки, Chromium-сценарии на синтетических данных,
  Docker-образ и его запуск, готовый Windows Bridge, сборки и воспроизводимость тем, внешний SDK. Телефон в этих
  тестах заменён тестовым транспортом: проверяется оркестрация, приватность и защитные правила.
* **На физическом телефоне:** отдельно по [протоколу](TRANSPORTS.md#manual-nokia-e52-test-protocol); результаты не
  подменяются автоматическими тестами. Пока протокол не пройден на конкретной модели и прошивке, «передано» не
  означает «установлено», а «установлено» — «работает».
* **Не декодируются:** контейнеры FPSX, VPL и образы ROFS; конвертер EKA1 → RPKG проверен на синтетических образах.
* **Не собран:** программа Device Agent для телефона (реализована сторона сервера и протокол,
  [AGENT.md](AGENT.md)).

Исторические отчёты сохранены в `docs/validation/`; они не заменяют текущий CI.
