# Возможности и проверка

Актуальное описание продукта — [README](../README.md), подключения —
[TRANSPORTS.md](TRANSPORTS.md), установка — [DOCKER_DEPLOYMENT.md](DOCKER_DEPLOYMENT.md).
Этот документ описывает значения статусов для разработчиков.

- `installed` — установщик сообщил результат установки; это не запуск.
- `launched` — подтверждён запуск в указанной среде.
- `failed` — операция завершилась ошибкой.
- `unsupported` — выбранная среда/транспорт не предоставляет функцию.
- `not-tested` — результата проверки нет.

Структурная проверка SIS, математическая подпись, доверие сертификату на телефоне,
успех эмулятора и работа на реальном устройстве — разные результаты.
Статическая совместимость `compatible` не подтверждает runtime-совместимость.

CI проверяет Python 3.11–3.13, реальные FFmpeg-кодеки, браузерные сценарии,
Docker, готовый Windows Bridge, сборки тем и внешний SDK. Физические E52/E72
проверяются отдельно по [протоколу](TRANSPORTS.md#manual-nokia-e52-test-protocol).
Исторические отчёты сохранены в `docs/validation/`; они не заменяют текущий CI.
