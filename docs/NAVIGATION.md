# Навигация SymPort

Боковое меню React-клиента — пять групп, раскрывающихся с анимацией. Источник правды —
`frontend/src/nav/routes.ts` (идентификаторы, иконки Lucide, статусы и редиректы).

| Группа | Страницы |
|---|---|
| Мой телефон | Обзор устройства · Файловый менеджер · Контакты · Сообщения · Календарь · Медиа · Резервные копии |
| Приложения | Каталог приложений · Мои приложения · Установочные пакеты · Зависимости и совместимость · Комплекты приложений |
| Персонализация | Темы оформления · [Редактор тем](P1_WORKSPACE.md) · Обои (в разработке) · Мастер рингтонов |
| Инструменты | Диагностика устройства · SymPort Revive · Certificate Inspector · Firmware & ROM Explorer · Jailbreak Manager (экспериментальный) · Журнал операций |
| Разработка и эмуляция | Emulator Lab · SDK и сборка · Тестирование приложений (в разработке) · Тестирование тем (в разработке) |

«Подключение» (`#phone/connection`) не в меню: открывается по карточке телефона в шапке бокового меню,
из «Настроек» и со страницы обзора.

## Маршруты и старые URL

Канонический вид — `#группа/страница?запрос`. Все прежние адреса работают и **заменяются** (без лишней
записи в истории), query сохраняется: `#inspector?source=device` → `#tools/certificates?source=device`.

| Было | Стало |
|---|---|
| `manager`, `files`, `connection`, `contacts`, `messages`, `calendar`, `media`, `backups` | `phone/overview`, `phone/files`, `phone/connection`, `phone/contacts`, `phone/messages`, `phone/calendar`, `phone/media`, `phone/backups` |
| `catalog`, `installed` | `apps/catalog`, `apps/installed` |
| `themes`, `ringtone` | `personalize/themes`, `personalize/ringtones` |
| `inspector`, `jailbreak`, `activity`, `device`, `updates` | `tools/certificates`, `tools/jailbreak`, `tools/activity`, `tools/diagnostics` (`updates` → `?view=updates`) |
| `lab`, `apps`, `overview` | `dev/lab`, `dev/sdk`, `dev/sdk?view=environment` |

Неизвестный адрес ведёт на обзор устройства. Контрольный список редиректов проверяется vitest
(`nav.test.tsx`) и Chromium (`check_react_workspace.cjs` ходит по старым hash-адресам).

## Поведение

* **Раскрытие.** Группа — кнопка с `aria-expanded`/`aria-controls`; закрытый список получает `inert`
  (не в порядке Tab). Группа с текущей страницей раскрывается сама. Состояние (открытые группы и режим
  «только значки») хранится в `localStorage` (`symport-nav-groups`, `symport-nav-compact`); это не персональные
  данные, при недоступном хранилище меню работает в пределах сессии.
* **Компактный режим.** Колонка 64 px, только значки; у ссылок сохраняется `aria-label`, подсказка
  показывается при наведении и фокусе. Включается в «Настройки» или кнопкой внизу меню.
* **Телефон ≤ 760 px.** Меню — выезжающая панель с затемнением; Esc и выбор пункта закрывают её, скрытая
  панель `inert`. Цели нажатия ≥ 44 px.
* **Карточка телефона** (под логотипом) строится из реального `discover`: модель и транспорт, если
  их сообщает подключение; «Телефон не подключён», «Статус неизвестен» при ошибке опроса. «Подключено»
  означает доступный транспорт, а не проверку телефона.
* **Низ меню:** настройки (язык, тема, компактное меню, ссылка на подключение), быстрые кнопки темы
  (пока отключена: интерфейс только светлый) и языка RU/EN.
* **Хлебные крошки** в верхней панели: `SymPort / группа / страница`, последняя — `aria-current="page"`.
* **Заготовки** (`Planned`): «В разработке», перечень планируемого и ссылки на уже работающие инструменты;
  никаких действующих элементов и результатов-имитаций. Пункты помечены в меню значком «Скоро».
* После смены страницы фокус переходит на основное содержимое; есть «К содержимому» (skip-link).
