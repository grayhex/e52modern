# Дорожная карта: управление Nokia E52 — от бытовых задач до разработки

Цель — один инструмент, который закрывает повседневную работу с E52 (файлы, контакты, резервные копии, медиа,
темы) и разработку (сборка, упаковка, анализ, тестирование). Принципы прежние: *reuse first*, каждая возможность
имеет честный уровень доказательства (см. [STATUS.md](STATUS.md)), **нет физического E52 ⇒ нет заявлений о работе на нём**.

## Как E52 вообще подключается (проверяемые факты)

Источники — третьи копии руководства пользователя E52 и описания Gammu (первичные страницы Nokia недоступны);
всё записано в `profiles/nokia-e52.toml` со статусом `stated`/`unknown`.

| Канал | Что известно | Что даёт SymPort |
|---|---|---|
| USB «Mass storage» | в руководстве E52 режим выбирается при подключении; **нужна карта памяти** | смонтированный том: файлы, резервная копия, SIS |
| USB «PC Suite» | Nokia PC Suite — только Windows | через Gammu/`symbian device` (не проверено на E52) |
| Режим Media transfer | **для E52 не подтверждён** | не используется |
| Gammu (AT/OBEX/Bluetooth) | поддерживает контакты, SMS, календарь, файловую систему у многих Nokia; запись E52 в базе Gammu не подтверждена | контакты (есть), календарь (read-only, новое) |
| Bluetooth OBEX | Object Push ≠ файловый менеджер; OBEX FTP требует, чтобы телефон открыл службу | не реализовано |

## Этапы

**R1 (сделано в этой ветке) — безопасность данных.** Полная резервная копия/проверка/восстановление, инвентарь SIS,
передача SIS на том без SDK, чтение календаря/задач, профиль E52 (USB-режимы, карта, медиа-форматы), `doctor` видит Gammu.

**R2 — повседневная полнота.**
* SMS: **только чтение**. Варианты: `gammu backupsms <file> -all` (по man-странице `-all` сохраняет сообщения на телефоне,
  а `-yes` их **удаляет** — поэтому `-yes` не используется никогда); формат файла «SMS Backup Format» в документации Gammu
  не описан, поэтому парсер без образца с реального телефона не пишется. Нужен снимок файла с E52 или `python-gammu`.
* ✅ Web-интерфейс для полной резервной копии (создание/проверка/восстановление/удаление, прогресс), инвентаря SIS и календаря (чтение) — см. [WEB_UI.md](WEB_UI.md). Проверен автотестами и Chromium на временных каталогах и поддельном Gammu, **не на E52**.
* Конвертация медиа: изображения → 240×320 (Pillow), аудио → MP3/AAC (ffmpeg), проверка по `media.*` профиля.
* Экспорт контактов/календаря в стандартные файлы (`.vcf`, `.ics`) и CSV.

**R3 — устройство как объект.** Единая карточка: модель/RM/прошивка (`gammu identify`, `*#0000#`), батарея/сигнал
(AT через `symbian device info --at-status`), память карты, режим USB. MTP/OBEX — только после подтверждения на E52.

**R4 — разработка и тестирование.** Нативный SDK и импорты E32 на реальных образцах, эмулятор EKA2L1 с собственными ROM,
`device stage` → ручной чек-лист → матрица совместимости с реальными прогонами.

**R5 — перспектива.** SDL-шаблоны, диагностический агент на Symbian, профили E71/E72/N95/N8.

## Как функция «взрослеет»

`реализовано` → `автотесты` → `сверено с независимой реализацией` → `эмулятор` → **`физический E52`**. Для всего, что
помечено «на E52 не проверено», есть пункт в чек-листе [DEVICE_TEST.md](DEVICE_TEST.md#функции-телефонного-рабочего-пространства);
результаты ручной проверки — единственный способ сменить статус.
