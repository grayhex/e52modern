# Следующие направления

Работающие возможности перечислены в [README](../README.md).

- Расширенный файловый менеджер: дополнительные OBEX-возможности и безопасные batch-операции.
- Проверенные на физических E52/E72 профили USB/Bluetooth, S60 Remote и PIM.
- Нативный Symbian Agent / SyncML с сохранением конфликтов и проверкой записи.
- Отдельный проект прошивки: проверенный механизм записи, подбор RM/product code,
  резервное копирование и восстановление. До этого Updates остаётся read-only.
- Ресурсы тем E72 под 320×240 и проверки соответствующей пользовательской прошивки.

Эти пункты не объявляются доступными функциями интерфейса. Контракт транспортов,
ограничения и протокол испытаний: [TRANSPORTS.md](TRANSPORTS.md).
