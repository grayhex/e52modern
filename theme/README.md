# E52 / CLEAR — тема для Nokia E52 (S60 3rd Ed. FP2, 240×320)

## Статус — читать первым

В репозитории **набор ресурсов темы** (PNG, цвета, геометрия, чек-лист), а **не готовый `.sis`**.
`.skn`/`.mif`/`.mbm` не создавались: их собирает Carbide.ui Theme Edition (S60v3 FP2, только Windows),
а подделывать бинарный `.skn` без проверки на телефоне нельзя — неверный файл может уронить оболочку.
Ничего из этого на реальном E52 **не проверялось**.

Геометрия и содержимое экрана не меняются (тема не двигает виджеты, не меняет шрифт и раскладку):
меню 3×4, статус-панель, 6 вкладок по 40 px, строка списка 24 px, софт-клавиши. Оригинальные иконки
приложений остаются системными.

Остальные значения и контраст по парам — в `theme/colours.json` (все пары ≥ 4.5:1).
Тёмный текст — на светлой теме, светлый — на тёмной; в Carbide.ui применяйте эти цвета ко всем
группам текста (список, выделение, софт-клавиши, статус-панель, popup, вкладки).

## Как собрать `.sis`

1. Carbide.ui Theme Edition → новый проект, платформа **S60v3 FP2**, 240×320 portrait.
2. Импортируйте PNG из `theme/assets/light/` (затем отдельный проект для `dark/`) по таблице выше.
3. Задайте цвета по таблице и `colours.json`.
4. Иконки приложений не подменяйте — оставьте системные.
5. Соберите пакет (`.sis`) средствами Carbide.ui; структура установки — как в
   `reference/05_REAL_NOKIA_PKG_REFERENCE.txt` (`.skn` → `\private\10207114\import\<id>`).
6. Подпишите (self-signed подходит не всегда для тем — при отказе установки нужен Open Signed / dev-сертификат).

## Проверка на телефоне (чек-лист)

- Сравнить фиксированную геометрию с `reference/00_original_user_240x320.png`.
- Читаемость: софт-клавиши, выделенная строка, индикаторы сети/батареи, календарь, входящие,
  popup «Параметры», список «Настройки», меню 3×4.
- Выделение при навигации во все стороны, входящий вызов, читаемость на солнце.
- Не все приложения применяют все цветовые группы одинаково — проверить каждое.

Не заявлять о готовности, пока тема не собрана и не проверена на устройстве.
